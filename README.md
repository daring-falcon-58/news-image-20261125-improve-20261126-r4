## How it was built

A new design, not a polish of round 3: a flat vector broadsheet drawn
programmatically with PIL (DejaVu + Noto) — every scene is rects, polygons
and lines; every letter is drawn text, so nothing can garble. The world map
uses Natural Earth 110m land outlines, simplified and embedded in the
composer. The image is 1024×1024 JPEG, 393,201 bytes (limit 1 MiB). The
composer asserts every headline wraps to at most 2 lines, every brief fits
its column on one line, the DATE CHECK fits 2 lines, and the layout ends
inside 1024 px — it failed six times during the build (fields line, two
over-long subs, three over-long list lines, DATE CHECK overflow) and each was
fixed by shortening copy and re-flowing, not by shrinking type below
legibility. Two runs of the composer produce identical bytes (sha256
`5168e6e80827bed3636ca080a9e4170fa7873c32d313ae656492be6a46237660`), and
`node main.ts` reproduces the same bytes twice.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
```

The program copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`). No network,
no secrets, deterministic — both runs write the same bytes.
